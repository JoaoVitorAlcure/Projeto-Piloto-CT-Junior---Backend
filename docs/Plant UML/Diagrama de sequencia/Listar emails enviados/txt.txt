@startuml
actor "Usuário" as U
participant "Cliente" as C
participant "API" as API
participant "Middleware JWT" as MW
database "Banco de Dados" as DB

U -> C: Solicita lista de emails
C -> API: GET /sent-emails + Bearer token
API -> MW: Valida token
alt Usuário não autenticado
    API --> C: 401 Não autorizado
else Usuário autenticado
    MW --> API: userId
    API -> DB: Busca emails enviados do usuário
    DB --> API: Lista de emails
    API --> C: 200 OK + emails
@enduml
